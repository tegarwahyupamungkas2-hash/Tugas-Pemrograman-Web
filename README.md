# Program Penilaian Nilai Mahasiswa
Program ini dibuat untuk tugas Pemrograman Web menggunakan HTML, CSS, dan JavaScript.
## Fitur
- Menginput nilai 5 mata kuliah.
- Menghitung total dan rata-rata nilai.
- Menentukan kategori nilai A sampai E.
- Menampilkan status lulus atau belum lulus.
## Materi
- HTML untuk membuat halaman.
- CSS untuk mengatur tampilan.
- JavaScript untuk perulangan `for` dan percabangan `if else`.
## Cara Menjalankan
1. Buka folder di vs code.
2. Run program `index.html`.
3. Masukkan nilai setiap mata kuliah.
4. Klik tombol Hitung Nilai.
5. Hasilnya akan muncul di halaman.
## File
- `index.html`
- `style.css`
- `script.js`
## Kesimpulan
Melalui program ini, penggunaan perulangan `for` dapat
diterapkan untuk menjumlahkan beberapa nilai secara otomatis.
Sementara itu, percabangan digunakan untuk menentukan
kategori nilai dan status kelulusan berdasarkan hasil
perhitungan rata-rata.
